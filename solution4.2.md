 I built a job application form using different HTML input types. I created personal information fields for full name, email, and phone with proper labels and required attributes. I used type="date" for date of birth and type="url" for portfolio URL with correct validation. For gender and preferred shift, I implemented radio buttons and kept the same name attribute for related options (e.g., name="gender" for all gender options) so that only one can be selected. I used checkboxes for skills like HTML, CSS, and JavaScript allowing multiple selections, and dropdowns using <select> for qualification and job role. For the cover letter, I used a <textarea> with rows and columns for multi-line text. I also added an example of a disabled field for Application ID using the disabled attribute. Finally, I completed the form with submit and reset buttons and ensured every field had a proper label for accessibility.
